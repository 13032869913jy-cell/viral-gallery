# AI Viral Collection · AI 爆款合集

静态页面，给运营查看可复刻的爆款视频，并对照搜集标准处理模板需求。不需要构建，浏览器直接读 Google 表格。

## 数据从哪来

条目在表格的 `items` 工作表，搜集标准在 `criteria` 工作表（名字以 `config.js` 的 `criteriaSheetName` 为准）。页面打开时拉取 CSV：

- 条目优先走 gviz 地址，失败再用 export 地址
- 标准按表格 id 和工作表名拼接 gviz 地址。拉不到时不显示标准面板，也不打断条目列表

表格需要设为「知道链接的任何人可查看」。条目表如果还是私有的，页面会提示去改共享，而不是一片空白。

改表格地址、条目表、标准表或搜索请求表的名字，只改 `config.js`。

## 怎么改状态

状态在表格里改，不在网页上改。打开页面上的「编辑状态（Google 表格）」，改下拉（是否复刻、各平台、模版是否适合、优先级、需求单字段、搜集标准等）后保存，回到页面点「刷新」。

「数据更新于」取条目里最新的 `updated_at`，没有可读时间时用本次拉取时间。「标准更新于」取标准表里最新的 `updated_at`。

## 下载

「一键下载全部视频」打开网盘文件夹。进去之后点右上角「下载」，即可把整个文件夹打包。网盘文件夹也需要「知道链接的任何人可查看」。

每条卡片上的「下载原视频」优先打开网盘里的原片；没有网盘链接时，在新标签打开原帖视频地址。

## 页面上能做什么

- 绿框是已复刻，红框是未复刻。站内模版还没上线时封面是灰的，并标「模版待上线」。
- 有原片和复刻片时，可以在「原版 / 复刻」之间切换。视频只在进入画面后静音循环播放。
- 筛选：已复刻、有模版、视频/图片、是否适合做模板、优先级。排序：最新（先按收录时间，再按播放）或最热（按播放）。
- 48 小时内收录的条目有 NEW。
- 填了需求单任一字段的卡片可以展开「模板需求单」，并「复制需求单」。
- 顶部「当前搜集标准」按 section 分组，其中「当前重点方向」会高亮。桌面端默认展开，手机上默认收起。面板里的「微调标准」打开标准表，需要表格编辑权限。
- 「手动搜索热点」不在网页上提交。有表格编辑权限的人点「去提交搜索」，在 `requests` 工作表新起一行，填写关键词，备注可选，状态留空。工作日 10:00–19:30（北京时间）每 30 分钟处理一次，每天最多 10 次。页面把状态为空的关键词显示为「排队中」，列出最近 10 条。还有排队中或搜索中的请求时，大约每 60 秒再读一次；变成已完成后会刷新条目。点「查看收录」只显示来源为「手动搜索：关键词」的卡片。

## 谁能改搜集标准

表格不要对所有人开放编辑。

1. **共享**里，一般访问权限设为「知道链接的任何人」→ **查看者**。网页和网盘链接才能被打开，但外人改不了格子。
2. 需要改表的人，再单独加为 **编辑者**。
3. 搜集标准那一页再锁一次：打开 `criteria` 工作表，菜单 **数据 → 保护工作表和区域**，保护整张工作表，只允许上面那些编辑者修改。条目表如果也要防误改，用同样的办法保护。

## 媒体链接会过期

原帖视频和封面很多在 video.twimg.com / pbs.twimg.com。这些链接会过期，原帖删除后也会打不开。页面已经不发送 Referer，否则视频地址会 403。长期应把视频和封面转到自有 CDN，再把表格里的链接换成新地址。
