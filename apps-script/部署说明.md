# 手动搜索：怎么接到表格上

给不写代码的人。做完以后，网页上的「提交搜索」才会可用。口令和密钥只放在 Apps Script 的脚本属性里，不要写进表格，也不要发到聊天记录里。

## 1. 打开脚本编辑器

1. 打开这张 Google 表格。
2. 菜单 **扩展程序 → Apps Script**。
3. 左边如果已经有一个 `Code.gs`，把里面的内容全删掉。
4. 打开本仓库的 `apps-script/Code.gs`，全选复制，粘贴进去。
5. 左上角项目名称可以写成「热点搜索」。点保存（软盘图标）。

## 2. 填写脚本属性

1. 左侧齿轮 **项目设置**。
2. 拉到下面 **脚本属性**，点 **添加脚本属性**。每一行是一个名字和对应的值：

| 属性 | 填什么 |
|---|---|
| `PASSCODE` | 你们自己定的口令。多个人可以用不同口令，用英文逗号隔开，例如 `alpha,beta`。口令本身不要含英文逗号。 |
| `WEBHOOK_URL` | 接收搜索任务的那个网址（对方提供）。 |
| `WEBHOOK_KEY` | 对方给的密钥。 |
| `DAILY_LIMIT` | 可选。每天最多接受几条搜索，不填就是 10。按北京时间计算。 |

如果对方说密钥不是放在 `Authorization` 里，再加这两行（不需要就不要加）：

| 属性 | 填什么 |
|---|---|
| `WEBHOOK_KEY_HEADER` | 对方指定的请求头名字。不填则用 `Authorization`。 |
| `WEBHOOK_KEY_PREFIX` | 密钥前面的前缀。不填则用 `Bearer `（Bearer 后面有一个空格）。对方不要前缀时，把这一项留成空值。 |

改口令或每日上限：只改这里的属性，保存即可，**不用重新部署**。

## 3. 运行一次 setup 并授权

1. 回到编辑器，顶部函数选择 `setup`，点 **运行**。
2. 弹出授权时，选自己的 Google 账号，点允许。权限包含这张表格，以及以后替你去通知搜索服务（访问外部网址）。
3. 跑完后，表格里应出现一个 `requests` 工作表，第一行是表头。已经有这个表的话，不会把旧数据清掉。

## 4. 部署成谁都能调用的 Web 应用

1. 右上角 **部署 → 新建部署**。
2. 类型选 **Web 应用**（点齿轮旁的类型）。
3. 执行身份选 **我**。
4. 访问权限选 **任何人**。
5. 点部署。如果再问一次授权，继续允许。
6. 复制给出的网址。它以 `/exec` 结尾。不要复制以 `/dev` 结尾的测试地址。

用浏览器打开这个 `/exec` 网址，页面上能看到 `搜索服务在线`，就说明部署好了。

## 5. 把网址填回网页

打开仓库里的 `config.js`，把 `APPS_SCRIPT_URL` 后面的空字符串换成刚才的 `/exec` 网址，保存并等网站更新。

如果不方便改仓库，把这个 `/exec` 网址发给 Kelly，让 Kelly 贴进 `config.js`。

网页上「手动搜索热点」不再显示「未配置」、提交按钮可以点，就说明接上了。

## 6. 以后怎么改

- 换口令、改每天次数、换通知地址或密钥：只改第 2 步的脚本属性，不用重新部署。
- 只有改了 `Code.gs` 里的代码，才需要 **部署 → 管理部署 → 编辑 → 版本选新版本 → 部署**。网址不用换。
